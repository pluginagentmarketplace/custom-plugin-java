### Product Manager Frameworks

#### RICE Prioritization
```
Score = (Reach × Impact × Confidence) / Effort

Reach: How many users affected (quarterly users)
Impact: How much impact (3x, 2x, 1x, 0.5x, 0.25x)
Confidence: Certainty level (100%, 80%, 50%)
Effort: Team-months to implement
```

#### OKRs (Objectives & Key Results)
```
Example Q3 OKRs:
Objective: Improve user retention
Key Result 1: Increase 30-day retention 60%→70%
Key Result 2: Reduce onboarding time 10→5 minutes
Key Result 3: Add 3 power-user features

Grade: 0.0 to 1.0 (0.7 is good)
```

## QA Engineering Path (8-14 months)

### QA Levels
```
Level 1: Manual Testing (3-6 months)
- Test plan creation
- Test case writing
- Manual execution
- Bug reporting

Level 2: Test Automation (3-4 months)
- Automation frameworks (Selenium, Cypress)
- CI/CD integration
- Regression testing
- Performance testing

Level 3: Advanced (3-6 months)
- API testing
- Security testing
- Load testing (k6, JMeter)
- Accessibility testing (WCAG)
```

### Testing Pyramid
```
        ▲
       ╱│╲
      ╱ │ ╲    E2E Tests (5%)
     ╱  │  ╲
    ╱───┼───╲
   ╱   Integration  ╲  Integration Tests (15%)
  ╱─────┼─────╲
 ╱ Unit Tests  ╲    Unit Tests (80%)
╱───────┼───────╲

Best coverage: Many unit, fewer integration, few E2E
```

### Testing Types
```
Functional Testing
- Unit tests (code functions)
- Integration tests (components together)
- E2E tests (full user flows)
- Regression tests (old features still work)

Non-Functional Testing
- Performance testing
- Load testing (many users)
- Stress testing (breaking point)
- Security testing
- Accessibility testing
- Compatibility testing
```

## Career Transitions

### IC to Manager Transition
```
Timeline: 3-6 months of transition
Challenges: Giving up coding, managing peers, different skillset
Success factors: Strong communication, tech background, people skills
Common mistakes: Too hands-on, playing favorites, avoiding hard conversations
```

### Technical to Product
```
Timeline: 6-12 months
Requires: Customer empathy, business thinking, less coding
Advantage: Technical background valuable for product sense
Growth path: Product Manager → Senior PM → Director of Product
```

### Engineer to DevRel
```
Timeline: 2-4 months
Requires: Communication skills, community passion, content ability
Advantage: Technical depth for credibility
Growth path: Developer Advocate → Senior DevRel → Head of DevRel
```

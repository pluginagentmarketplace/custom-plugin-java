## Decision Framework

### Choosing a Path

**Ask Yourself:**
1. How much time can I dedicate? (2-4 hours/day minimum)
2. Do I have a goal? (job? transition? skill?)
3. What's my background? (CS degree? bootcamp? self-taught?)
4. What industries interest me? (fintech, healthcare, gaming?)
5. What's my learning style? (hands-on? reading? mentoring?)

**Decision Tree:**
```
Are you employed?
├─ YES: Go gradual (2-3 hours/day, 12+ months)
└─ NO: Go intensive (4+ hours/day, 3-6 months)

Do you know what you want?
├─ YES: Pick specific roadmap
└─ NO: Start with "/learn" assessment

Do you like working alone?
├─ YES: Backend, Data, DevOps
└─ NO: Frontend, Product, DevRel

Do you prefer structure?
├─ YES: Java, Angular, Kubernetes
└─ NO: Python, React, Go

Do you want high salary?
├─ YES: Blockchain, AI/ML, Architect
└─ NO: Any path works
```

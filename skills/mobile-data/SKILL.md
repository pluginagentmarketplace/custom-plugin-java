## Mobile Development Paths

### iOS Developer (12-18 months)
```swift
1. Swift fundamentals (3 months)
   → Variables, functions, OOP, protocols

2. SwiftUI essentials (3 months)
   → Views, state, navigation, forms

3. Intermediate (3 months)
   → Network requests, CoreData, testing

4. Advanced (3+ months)
   → ARKit, performance, App Store deployment

5. Projects: Calculator, Weather App, Social App
```

### Android Developer (12-18 months)
```kotlin
1. Kotlin fundamentals (3 months)
   → Variables, OOP, coroutines, null safety

2. Jetpack Compose (3 months)
   → Composables, state, navigation, lists

3. Intermediate (3 months)
   → Room DB, ViewModel, API calls, testing

4. Advanced (3+ months)
   → Material Design, performance, Play Store

5. Projects: TODO App, News Reader, Chat App
```

### React Native (9-12 months)
```typescript
1. React fundamentals FIRST (4 months)
   → Components, hooks, state, routing

2. React Native specific (3 months)
   → Native modules, navigation, performance

3. Production (2-3 months)
   → Testing, deployment, native features

4. Projects: Weather app, E-commerce, Social
```

### Flutter (9-12 months)
```dart
1. Dart language (2 months)
   → Variables, functions, OOP, async

2. Flutter widgets (3 months)
   → Stateless, stateful, navigation, forms

3. Intermediate (3 months)
   → APIs, Firebase, local storage, testing

4. Advanced (2+ months)
   → Performance, animations, Play Store/App Store

5. Projects: Calculator, Weather, E-commerce
```

## Data Science & AI Roadmap

### Data Scientist (10-16 months)
```python
1. Python fundamentals (2 months)
   → Variables, functions, OOP, pandas, numpy

2. Data analysis (3 months)
   → EDA, visualization (matplotlib, seaborn)

3. Machine learning (4 months)
   → Regression, classification, clustering
   → Scikit-learn, XGBoost, LightGBM

4. Statistics & testing (2 months)
   → Hypothesis testing, A/B testing

5. Projects: Titanic prediction, Iris classification
```

### Data Engineer (14-20 months)
```python
1. Python + SQL (3 months)
   → Advanced SQL, query optimization

2. ETL pipelines (3 months)
   → Apache Airflow, workflow orchestration

3. Big data processing (4 months)
   → Apache Spark, distributed computing

4. Data warehousing (3 months)
   → Snowflake, BigQuery, dimension modeling

5. Streaming (2 months)
   → Kafka, real-time data processing

6. Projects: ETL pipeline, data warehouse
```

### AI Engineer (10-16 months)
```python
1. Deep learning basics (3 months)
   → PyTorch, neural networks, CNNs, RNNs

2. Transformers & LLMs (3 months)
   → BERT, GPT, Hugging Face Transformers

3. Prompt engineering (2 months)
   → LLM APIs (OpenAI, Anthropic), LangChain

4. RAG systems (2 months)
   → Vector DBs, embeddings, retrieval

5. Deployment (2 months)
   → FastAPI, model serving, optimization

6. Projects: Chatbot, recommendation system
```

### Machine Learning Engineer (16-24 months)
```python
1. ML fundamentals (4 months)
   → Algorithms, feature engineering, evaluation

2. Production ML (4 months)
   → Training pipelines, versioning, monitoring

3. Feature engineering (3 months)
   → Feature stores, feature selection

4. Model serving (3 months)
   → FastAPI, TensorFlow Serving, optimization

5. Distributed training (2 months)
   → Ray, Horovod, multi-GPU training

6. Projects: Recommendation system, time-series
```

### MLOps Engineer (12-18 months)
```
1. MLOps fundamentals (2 months)
   → Model versioning, experiment tracking

2. CI/CD for ML (3 months)
   → GitHub Actions, model automation

3. Infrastructure (3 months)
   → Docker, Kubernetes, cloud platforms

4. Monitoring & observability (2 months)
   → Model drift, performance monitoring

5. Orchestration (2 months)
   → Kubeflow, Argo, workflow automation

6. Projects: ML pipeline, model monitoring
```

## Technology Stacks

### Mobile Development

#### iOS
- **Language**: Swift 5.0+
- **UI**: SwiftUI (modern), UIKit (legacy)
- **Databases**: CoreData, Realm
- **Networking**: URLSession, Alamofire
- **Testing**: XCTest, Quick
- **Deployment**: Xcode, App Store Connect

#### Android
- **Language**: Kotlin
- **UI**: Jetpack Compose (modern), XML (legacy)
- **Databases**: Room, Realm
- **Networking**: Retrofit, OkHttp
- **Testing**: JUnit, Espresso
- **Deployment**: Android Studio, Play Store

#### Cross-Platform
- **React Native**: npm, Expo, bare React Native
- **Flutter**: Dart SDK, pub.dev packages
- **Comparison**: React Native has more jobs, Flutter has better performance

### Data & AI Stack

#### Data Science
- **Languages**: Python 3, R
- **Computation**: NumPy, Pandas, SciPy
- **Visualization**: Matplotlib, Seaborn, Plotly
- **ML Libraries**: Scikit-learn, XGBoost, LightGBM
- **Notebooks**: Jupyter, Colab
- **Deployment**: Streamlit, FastAPI

#### Data Engineering
- **Languages**: Python, SQL, Scala
- **Processing**: Apache Spark, Dask
- **Orchestration**: Apache Airflow, Prefect, Dagster
- **Databases**: PostgreSQL, Snowflake, BigQuery
- **Streaming**: Kafka, Kinesis
- **IaC**: Terraform, CloudFormation

#### AI & LLMs
- **Frameworks**: PyTorch, TensorFlow, JAX
- **LLMs**: Hugging Face, LangChain, OpenAI API
- **Vector DBs**: Pinecone, Weaviate, Chroma
- **Serving**: FastAPI, Ray Serve, TensorFlow Serving
- **Cloud**: AWS SageMaker, GCP Vertex AI, Azure ML

## Quick Decisions

### Mobile: Which Platform?

**Choose iOS if:**
- Target wealthy users
- Want highest app quality
- Willing to spend on Mac/iPhone
- Building premium products

**Choose Android if:**
- Want largest market
- Budget-conscious
- Building for emerging markets
- Want free tools

**Choose React Native if:**
- Need JavaScript skills
- Want code sharing
- Have tight timeline
- Building MVP

**Choose Flutter if:**
- Want best performance
- Building complex UI
- Like Google ecosystem
- Want single codebase

### Data: Which Role?

**Choose Data Scientist if:**
- Love statistics and math
- Want to build models
- Happy with 20% productivity code
- Like research and experimentation

**Choose Data Engineer if:**
- Love infrastructure
- Want to build systems
- Like 80% production code
- Building data platforms

**Choose ML Engineer if:**
- Want production focus
- Like both ML and eng
- Building real products
- 50-50 research and code

**Choose AI Engineer if:**
- Excited about LLMs/ChatGPT
- Want cutting-edge tech
- Building with APIs
- Emerging role with high demand

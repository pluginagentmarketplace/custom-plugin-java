# 04 - DevOps & Cloud Engineer

## Overview
Master modern infrastructure, containerization, and cloud operations. This agent guides you through **DevOps**, **Docker**, **Kubernetes**, **AWS**, **Terraform**, **Linux**, and cloud platforms roadmaps, enabling you to build scalable, reliable, and automated infrastructure.

## Specialized Roadmaps
- ✅ **DevOps Roadmap** (general DevOps practices)
- ✅ **DevOps Beginner** (entry-level concepts)
- ✅ **Docker** (containerization technology)
- ✅ **Kubernetes** (container orchestration)
- ✅ **Terraform** (Infrastructure as Code)
- ✅ **AWS** (Amazon Web Services)
- ✅ **Linux** (OS and system administration)
- ✅ **Cloudflare** (CDN and DDoS protection)
- ✅ **GitOps** (Infrastructure management via Git)

## Key Competencies

### Foundations (2-4 months)
- Linux fundamentals (file system, permissions, processes)
- Networking basics (IP, DNS, TCP/IP, HTTP/HTTPS)
- Shell scripting (Bash, Zsh)
- Version control (Git, GitHub, GitLab)
- Web servers (Nginx, Apache)
- Basic system administration

### Intermediate (4-8 months)
- Docker containerization
- Kubernetes basics (pods, deployments, services)
- Infrastructure as Code (Terraform, CloudFormation)
- CI/CD pipelines (GitHub Actions, GitLab CI, Jenkins)
- Cloud platforms (AWS, GCP, or Azure)
- Monitoring and logging (Prometheus, ELK)
- Configuration management

### Advanced (8-16 months)
- Kubernetes advanced (Helm, operators, custom resources)
- Multi-cloud and hybrid deployments
- Service meshes (Istio, Linkerd)
- GitOps workflows (ArgoCD, Flux)
- Disaster recovery and high availability
- Security hardening and compliance
- Cost optimization
- Advanced networking and storage

## Learning Path Recommendation
1. **Start with Linux fundamentals** (essential for everything)
2. **Learn Docker** - containerization is foundational
3. **Add Kubernetes** - production container orchestration
4. **Choose cloud platform**: AWS (70% market share), GCP, or Azure
5. **Master Infrastructure as Code**: Terraform or CloudFormation
6. **Specialize**: GitOps, Service Mesh, Cost Optimization, or Security

## Tools & Technologies

### Core Infrastructure
- **Containerization**: Docker, containerd, Podman
- **Orchestration**: Kubernetes, Docker Swarm
- **Container Registry**: Docker Hub, AWS ECR, Google Artifact Registry

### Infrastructure as Code
- **Configuration Management**: Terraform, CloudFormation, Pulumi
- **Provisioning**: Vagrant, Packer
- **Configuration**: Ansible, Puppet, Chef

### CI/CD Tools
- **GitHub**: GitHub Actions, GitHub Workflows
- **GitLab**: GitLab CI/CD
- **Jenkins**: Pipeline as Code
- **Cloud Native**: Cloud Build (GCP), CodePipeline (AWS)

### Kubernetes Ecosystem
- **Package Manager**: Helm
- **Ingress**: Nginx Ingress, Kong
- **Service Mesh**: Istio, Linkerd
- **GitOps**: ArgoCD, Flux
- **Operators**: Kubeflow, Prometheus Operator
- **Monitoring**: Prometheus, Grafana, Datadog

### Cloud Platforms

#### AWS
- **Compute**: EC2, Lambda, Fargate, ECS
- **Storage**: S3, EBS, EFS
- **Networking**: VPC, CloudFront, Route53
- **Databases**: RDS, DynamoDB, ElastiCache
- **Management**: CloudFormation, Systems Manager

#### GCP
- **Compute**: Compute Engine, Cloud Run, GKE
- **Storage**: Cloud Storage, Persistent Disks
- **Networking**: Cloud CDN, Cloud Load Balancing
- **Databases**: Cloud SQL, Firestore, Bigtable
- **Management**: Deployment Manager, Config Connector

#### Azure
- **Compute**: VMs, App Service, Container Instances, AKS
- **Storage**: Blob Storage, Managed Disks
- **Networking**: Virtual Networks, Application Gateway
- **Databases**: Azure SQL, Cosmos DB, Azure Cache
- **Management**: Resource Manager, Azure DevOps

### Monitoring & Observability
- **Metrics**: Prometheus, Graphite, Datadog
- **Visualization**: Grafana, Kibana
- **Logging**: ELK Stack, Loki, Splunk
- **Tracing**: Jaeger, Zipkin, Tempo
- **Alerting**: AlertManager, PagerDuty

### Security & Compliance
- **Secret Management**: Vault, AWS Secrets Manager
- **Container Security**: Trivy, Aqua, Falco
- **Policy Enforcement**: OPA/Gatekeeper, Kyverno
- **Scanning**: SonarQube, Snyk, WhiteSource

### Networking & Load Balancing
- **Load Balancers**: Nginx, HAProxy, Envoy
- **API Gateway**: Kong, AWS API Gateway, Apigee
- **Service Mesh**: Istio, Linkerd, Kuma
- **Network Policy**: Cilium, Calico

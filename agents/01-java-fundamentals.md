# Java Fundamentals Agent

## Overview

This agent provides comprehensive guidance on Java fundamentals, helping developers understand core language concepts from basic syntax to advanced features.

## Core Capabilities

### 1. Java Syntax & Data Types
- Primitive types (byte, short, int, long, float, double, char, boolean)
- Reference types and Objects
- Variables and constants (final)
- Type conversion and casting
- Operators and expressions

### 2. Control Flow
- Conditional statements (if, switch)
- Loops (for, while, do-while, enhanced for)
- Break, continue, return
- Pattern matching (Java 17+)
- Switch expressions (Java 14+)

### 3. Methods & Functions
- Method declaration and invocation
- Parameters and return types
- Method overloading
- Variable arguments (varargs)
- Recursion

### 4. Packages & Modules
- Package organization
- Import statements
- Access modifiers (public, private, protected)
- Java Platform Module System (JPMS)
- Module-info.java

## Example Prompts

- "Explain Java primitive types and when to use each"
- "How does switch expression work in Java 17?"
- "Create a modular Java project structure"
- "What are sealed classes in Java?"

## Quick Start

```java
// HelloWorld.java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

// Compile and run
// javac HelloWorld.java
// java HelloWorld
```

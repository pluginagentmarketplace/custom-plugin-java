# 06 - Leadership & Specializations

## Overview
Master non-technical leadership and specialized roles essential for product success. This agent covers **Product Manager**, **Engineering Manager**, **Technical Writer**, **DevRel Engineer**, **QA**, and **UX Design** roadmaps, enabling career transitions to leadership, advocacy, and specialized domains.

## Specialized Roadmaps
- ✅ **Product Manager** (product strategy + roadmapping)
- ✅ **Engineering Manager** (team leadership + mentoring)
- ✅ **Technical Writer** (documentation + content)
- ✅ **DevRel Engineer** (developer advocacy + community)
- ✅ **QA Engineer** (quality assurance + testing)
- ✅ **UX Design** (user experience + design systems)

## Key Competencies

### Product Manager (10-18 months)

#### Foundations
- Product strategy and vision
- Market research and competitive analysis
- User research and personas
- Product roadmapping
- OKRs and KPIs
- Go-to-market planning

#### Core Skills
- Requirements gathering and prioritization
- Stakeholder management (engineering, design, sales)
- Data analysis and metrics
- A/B testing and experimentation
- Pricing and monetization strategies
- Customer feedback loops

#### Advanced Topics
- Platform strategy
- International expansion
- Product portfolio management
- Venture capital and fundraising
- M&A integration
- Product analytics

### Engineering Manager (12-20 months)

#### Team Leadership
- Hiring and team building
- One-on-ones and feedback
- Performance management
- Career development and growth
- Organizational design
- Remote team management

#### Technical Leadership
- System design decisions
- Technical debt management
- Architecture reviews
- Technology strategy
- Mentoring and knowledge transfer
- Technical interviews

#### Operations
- Sprint planning and retrospectives
- Capacity planning
- Risk management
- Budget and resource allocation
- Cross-team coordination
- Incident response leadership

#### Career Transitions
- Individual Contributor → Tech Lead → Manager
- Manager → Director → VP Engineering
- Product focus vs people focus vs architecture focus

### Technical Writer (8-12 months)

#### Documentation Types
- API documentation
- User guides and tutorials
- Architecture documentation
- FAQs and troubleshooting
- Release notes
- Blog posts and content marketing

#### Skills
- Technical writing principles (clarity, conciseness)
- Markdown and documentation tools
- Single-source of truth documentation
- Audience analysis and persona mapping
- Information architecture
- Content management systems

#### Tools & Platforms
- Markdown editors (VS Code, Obsidian)
- Documentation platforms (Docusaurus, MkDocs, GitBook)
- Wiki systems (Confluence, Notion)
- API documentation (Swagger, OpenAPI)
- Static site generators (Jekyll, Hugo)
- Version control for docs (Git)

### DevRel Engineer (10-16 months)

#### Developer Advocacy
- Community building
- Developer conferences and speaking
- Content creation (blogs, videos, demos)
- Feedback loops to product
- Onboarding and developer experience
- Open source initiatives

#### Community Management
- Forum management (Discord, Slack)
- Social media strategy
- Event organization
- Mentoring and support
- Ambassador program
- Feedback aggregation

#### Developer Experience
- SDK design and UX
- Documentation quality
- Sample projects and templates
- API design for usability
- Developer surveys
- Metrics and analytics

### QA Engineer (8-14 months)

#### Testing Fundamentals
- Test types (unit, integration, E2E, performance, security)
- Test automation frameworks
- Test planning and strategy
- Defect lifecycle management
- Test case design
- Risk-based testing

#### Advanced Topics
- Test automation architecture
- CI/CD testing integration
- Performance and load testing
- Security testing (SAST, DAST)
- Mobile app testing
- Accessibility testing

#### Tools
- **Automation**: Selenium, Cypress, Playwright, TestNG
- **Manual**: TestRail, Zephyr, Azure Test Plans
- **Performance**: JMeter, Locust, K6
- **Mobile**: Appium, Detox, XCUITest
- **Security**: Burp Suite, OWASP ZAP, SonarQube

### UX Design (12-18 months)

#### Fundamentals
- User research methods
- Persona development
- User journey mapping
- Information architecture
- Wireframing and prototyping
- Usability testing

#### Design Skills
- Visual design principles
- Design systems creation
- Accessibility (WCAG)
- Mobile vs web design
- Responsive design
- Animation and micro-interactions

#### Tools
- **Design**: Figma, Sketch, Adobe XD
- **Prototyping**: Figma, Framer, Protopie
- **Research**: UserTesting, Hotjar
- **Collaboration**: Miro, Mural
- **Design Systems**: Storybook, Zeroheight

## Learning Path Recommendations

### Product Manager Track
1. **Start**: Product fundamentals (3-4 months)
2. **Deepen**: Market research + data analysis (3-4 months)
3. **Specialize**: B2B or B2C product strategy (3-6 months)
4. **Advanced**: Portfolio management or scale-up strategy (6+ months)

### Engineering Manager Track
1. **Prerequisite**: 3-5 years as strong IC
2. **Start**: Manager fundamentals and people skills (3-4 months)
3. **Deepen**: Technical leadership (3-4 months)
4. **Advanced**: Organizational design and strategy (6+ months)

### Technical Writer Track
1. **Start**: Writing fundamentals and documentation (2-3 months)
2. **Deepen**: Technical tools and platforms (2-3 months)
3. **Specialize**: API docs, user guides, or content marketing (2-3 months)

### DevRel Track
1. **Start**: Developer experience foundations (2-3 months)
2. **Build**: Community and content skills (3-4 months)
3. **Deepen**: Metrics and program management (3-4 months)

### QA Track
1. **Start**: Testing fundamentals (2-3 months)
2. **Deepen**: Test automation (3-4 months)
3. **Specialize**: Performance, security, or mobile testing (3-6 months)

### UX Design Track
1. **Start**: Design principles and research (2-3 months)
2. **Learn**: Design tools (Figma) (1-2 months)
3. **Build**: Design system or product (4-6 months)
4. **Deepen**: Advanced UX and accessibility (3-6 months)

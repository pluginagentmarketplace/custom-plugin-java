- Resources are curated but not automatically updated
- Job market data is point-in-time (recommend checking current sources)
- Some advanced topics require 5+ years experience
- Certain specializations have steep learning curves

## Migration Guide

### From Standard Roadmap.sh
If migrating from using roadmap.sh directly:
1. Use `/learn` instead of browsing all roadmaps
2. Use `/progress` instead of manual tracking
3. Use `/explore` for deep-dives
4. Use specialized agents for expert guidance

### From Other Learning Platforms
1. Import your learning goals with `/learn`
2. Get personalized path recommendations
3. Track progress with `/progress`
4. Find resources with `/resources`

# /learn

Start your learning journey with personalized path recommendations based on your goals and experience level.

## Usage

```
/learn
```

## What It Does

The `/learn` command provides:

- **Experience Level Assessment**: Quick quiz to determine your current level (Beginner/Intermediate/Advanced)
- **Goal Setting**: Identify what you want to learn (get a job, skill transition, specialization)
- **Path Recommendation**: Personalized roadmap selection from the 69 available roadmaps
- **Time Estimation**: How long your chosen path typically takes
- **Agent Assignment**: Connect you with the specialized agent for your path
- **Resource List**: Recommended resources, projects, and best practices

## Example Scenarios

### New to Development (Beginner)
```
/learn
→ Question: "First time coding?"
→ Answer: "Yes"
→ Recommendation: Frontend Beginner or Backend Beginner
→ Agent: Web Development Specialist or Backend Systems Architect
→ Time: 6-12 months to first job
→ Start: HTML/CSS fundamentals
```

### Career Transition (Intermediate)
```
/learn
→ Question: "Current role?"
→ Answer: "Frontend Developer"
→ Recommendation: Backend Developer roadmap
→ Agent: Backend Systems Architect
→ Time: 6-9 months transition
→ Start: Choose Node.js, Python, or Java
```

### Specialization (Advanced)
```
/learn
→ Question: "Want to specialize?"
→ Answer: "System Design"
→ Recommendation: System Design roadmap
→ Agent: Architecture & Security Specialist
→ Time: 6-12 months to mastery
→ Start: Scalability fundamentals
```

## Follow-up Actions

After `/learn`, you can:

1. **`/explore`** - Deep dive into specific roadmap
2. **`/progress`** - Track your learning journey
3. **Ask Questions** - "What's X?", "How do I learn Y?"
4. **Get Resources** - "Show me best tutorials for [topic]"
5. **Build Projects** - "What should I build next?"

## Pro Tips

✅ Be honest about your current level
✅ Set clear goals (job type, salary, timeline)
✅ Pick ONE primary path, add complementary skills later
✅ Review your path quarterly as interests change
✅ Join community for accountability

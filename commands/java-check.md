# Java Check Command

Verify Java development environment is properly configured.

## What This Command Does

1. Checks Java version
2. Verifies JAVA_HOME is set
3. Checks Maven installation
4. Checks Gradle installation
5. Displays environment summary

## Usage

```
/java-check
```

## Expected Output

- Java version (recommend 17 or 21)
- JAVA_HOME path
- Maven version
- Gradle version
- Build tool recommendations

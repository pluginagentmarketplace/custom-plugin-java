# Java Debug Command

Diagnose and troubleshoot Java application issues.

## What This Command Does

1. Analyzes stack traces
2. Identifies common errors
3. Checks JVM settings
4. Provides solutions

## Usage

```
/java-debug [error-type]
/java-debug OutOfMemoryError
/java-debug ClassNotFoundException
```

## Common Issues

- **OutOfMemoryError** - Heap/Metaspace analysis
- **ClassNotFoundException** - Classpath issues
- **NoSuchMethodError** - Version conflicts
- **StackOverflowError** - Recursion problems
- **NullPointerException** - Null handling
